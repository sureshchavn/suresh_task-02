# Laundry Wallah / Laundry Mart

A simple HTML-based laundry service website created as Task-2.

## Project Description

Laundry Wallah / Laundry Mart is a basic web page designed using HTML. The website provides information about laundry services, pricing details, and a simple booking section for customers.

## Features

* Welcome section
* Laundry service image
* List of available services
* Price list displayed using a table
* Customer booking form
* Contact information footer

## Technologies Used

* HTML5

* Special Garment Care

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
4. The website will load locally.
